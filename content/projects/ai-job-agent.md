A multi-agent job-search system with **LangGraph** tool routing, a **RAG** pipeline over a
vector store for context-aware recommendations, and **SQLAlchemy** persistence behind JWT
auth. Frontend in React, deployed on Vercel and Render with CI/CD.

**Stack:** Python · LangGraph · FastAPI · React · PostgreSQL · Docker
